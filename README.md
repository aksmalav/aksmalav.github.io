# aksmalav.github.io

Personal site of Akshay Malavade, live at **https://aksmalav.github.io**

- `index.html`: portfolio with selected product case studies, experience, and an embedded career mini-game
- `game.html`: the standalone "Play my career" game, a two-minute pixel-art walk from Rutgers to Columbia

Built as plain HTML, CSS, and JavaScript in one file each, with no build step, using Claude as a coding partner.
